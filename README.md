# DJI Bereikplanner

Kijk of je met je DJI-drone ergens naartoe kunt vliegen: accu (met wind en temperatuur) én signaal (met gebouwen, bomen en terrein).

Open de app: https://pepijnvette-cyber.github.io/dji-bereikplanner/

No-fly-zones: officiële Nederlandse UAS-zones (Regeling zonering onbemande luchtvaartuigen, IenW, versie feb 2026).
Data: OpenStreetMap (Overpass, Nominatim), Open-Meteo (weer), AWS Terrain Tiles (terrein), DJI-specificaties.
Planningshulp, geen garantie. In de EU: altijd zicht op je drone (VLOS) en max 120 m.
